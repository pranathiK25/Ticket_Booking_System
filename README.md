
# 🎟️ High-Concurrency Ticket Booking System
Welcome to my Ticket Booking System! 🚀

---

## 💡 About
BookMyShow - style backend where thousands of users can try to book the same seat simultaenously.

- **Java**  
- **Spring Boot**  
- **PostgreSQL** 

---

Flow : 
* Login / SignUp
* Movie
* Theatre
* Show / Screen
* Seats
* Book Ticket
* View / Cancel Booking
